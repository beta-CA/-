# 统一20轮论文图源

这6幅图全部重新绘制。数据只来自当前 `distilling_uniform20_v2` 的已保存真实日志和预测记录。
旧版10轮教师及10→20轮预算对照没有用于本次图形。

## 印刷与图例

- 最终宽度为模板单栏的8.125 cm，文字基准9 pt，数据线1 pt，坐标线0.75 pt。
- PNG按600 dpi导出，SVG保留可编辑的文字和矢量线。
- 黑白或灰度样式，使用不同线型和点形区分模型；不用多组阴影或多条种子曲线。
- 图2和图5各只保留教师、普通学生、蒸馏学生3条均值曲线，图例置于数据稀疏区。
- 图3和图4只保留蒸馏均值及其误差线与普通学生参考线，图例在图内顶部，仅2项。
- 图6用白色和灰色柱区分两种学生，图例2项。所有数据图的坐标与图例均为中文。
- 图片内不写标题、图注或“注”，图外也不生成说明文字。统计定义由论文正文说明。

2. Zhao等的DKD论文：<https://arxiv.org/pdf/2203.08679>。参考清晰的教师学生流程组织与结果展示，未使用其数据或插图。

   参考最终尺寸验读、减少装饰、轴和单位完整、矢量文字可编辑等原则；本中文模板采用9 pt，没有套用该刊5～7 pt的具体字号。
4. Cambridge官方插图指南：<https://www.cambridge.org/core/services/aop-file-manager/file/5da6dc5e807d44780a804757>。
   参考按最终尺寸导出、保留源文件及高分辨率组合图的要求。

## 各图统计定义

1. 原创流程图。教师冻结，学生同时接受教师概率与真实标签监督；虚线表示反向更新学生。
2. 验证准确率随轮次的变化。每条曲线是种子0、1、2的逐轮均值，未平滑，三个模型均有完整20轮。
3. 温度单因素结果。固定α=0.25，种子0和1；点为准确率均值，误差线为样本标准差。水平参考线为同两个种子的普通学生均值69.810%。
4. 权重单因素结果。固定T=2，种子0和1；点为准确率均值，误差线为样本标准差。α=0不重复绘制数据点，以普通学生水平参考线表示。
5. 验证交叉熵随轮次的变化。每条曲线是种子0、1、2的逐轮均值，未平滑；不再绘制旧训练预算比较。
6. 15个等宽分箱计算的期望校准误差，每个柱对应一个模型种子的10000条最终预测；置信度1包含在最后一箱。此项为事后诊断，越小越好。

## 重新绘制

先从 [v2.0.0发布页](https://github.com/beta-CA/-/releases/tag/v2.0.0) 下载 `distilling-weights-v2.0.0.zip`，将其中的 `runs_uniform20/` 解压到仓库根目录；仓库已包含对应的 `results_uniform20/`。在已安装Matplotlib与NumPy、且有宋体和Times New Roman字体的环境中，从仓库根目录执行：

```powershell
python paper_figures_uniform20/draw_uniform20_figures.py --output-root ./redrawn_figures
```

默认项目根目录为脚本目录的父目录，也可用 `--project-root` 指定其他完整实验目录。

该命令只读取统计表、日志与预测记录，不加载模型，不训练，不重新访问测试图像。
`figure_manifest.json`记录每幅图与全部16份输入记录的SHA-256，便于核对来源。
本目录不包含内部QA联系表。重新绘制只导出6幅PNG、6幅SVG与来源清单。

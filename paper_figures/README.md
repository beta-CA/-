# 论文中文图

图1至图6为论文插图，图7为类别指标的补充图。图中说明、轴名称和图例使用中文，采用适合黑白打印的线型、标记和纹理。
PNG为500 dpi成图；SVG保留可编辑文字及矢量图形。

在仓库根目录运行：

```powershell
python paper_figures/draw_paper_figures.py
```

脚本只读取同目录`data/`中的最小数据副本并重绘图，不加载模型，不训练，也不重新测试。
绘图使用Matplotlib和NumPy，中文字体为宋体（SimSun），英文字母和数字为Times New Roman。
为保持文字与论文版式一致，请在安装相应字体的环境中运行；已有SVG也可直接在矢量编辑软件中修改文字样式。
各图按3.2英寸宽度绘制，其中图1最终高度为3.6英寸。图1为原创流程示意图。

`figure_manifest.json`保存现成PNG/SVG的实际SHA-256及对应文件名；重新绘图后脚本会更新清单。
SVG的生成时间与内部标识可能使重复生成的文件哈希变化，应以同次生成后的清单为准。
数据来源和裁剪方式见`data/DATA_NOTE.md`。图6的ECE为事后补充诊断。

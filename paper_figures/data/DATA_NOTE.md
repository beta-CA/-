# 论文中文图的最小数据副本

这些数据来自已完成并通过文件与来源审计的正式CIFAR-10实验记录，只用于复现论文插图。
这里没有新增训练、重新测试或修改实验数值。

- `inputs/results_extended/summary.json`、`runs_metrics.csv`和`learning_budget_comparison.csv`逐字节复制正式汇总。
- `audited_results.json`只保留主实验9个模型的逐轮日志，删去绝对路径、模型配置及其他作图不需要的元数据。
- `classes_analysis.json`只保留图7需要的类别F1配对增益均值/样本标准差，以及图6需要的6个学生模型ECE值。
- ECE是实验完成后的补充诊断，采用15个等宽置信度分箱，不是新训练实验或预先设置的主要优化目标。
- 温度与权重实验各2个随机种子，主实验与类别增益为3个随机种子；默认配置复用，不能重复计为独立实验。

数据副本没有本机路径配置、访问令牌或密码。完整正式记录和权重仍以v1.0.0发布资产为准。
